보고서 본문 그림 가운데 확대해서 보고, 항목을 켜고 끄고, 값도 바로 확인하면 좋은 그림은 인터랙티브로 제공한다. 즉 웹에서 더 자유도 높게 탐색할 수 있도록 구성했다. 아래 플롯은 버튼을 눌러야 불러와지므로, 페이지 자체는 가볍게 열린다.

노트

이 페이지는 본문 어디를 보완하나

  • 확장 자료에서 사용하는 그림 1–12를 웹에서 탐색할 수 있게 확장했다(확대·축소, 범례 켜기·끄기, 값 확인).
  • 메인 보고서(PDF)는 지면 흐름에 맞춰 그림을 1–8로 재번호했다. 혼동되면 연결표를 참고한다.
  • 지면 제약으로 생략된 세부 값을 마우스로 바로 확인할 수 있다.
  • 네트워크 레이아웃은 구조를 보기 위한 보조 장치다. 거리와 위치를 정밀한 값으로 해석하지 않는다.

추천 탐색 순서(메인 보고서 흐름)

  • 두 속도(그림 1–4): 시간·분야·토픽 신호로 전체 지형을 잡는다.
  • 허브(그림 5–7): 국가·유형 차원에서 근거가 어디에 쌓이는지 본다.
  • 한국(그림 8–12): 유입·조달 비대칭과 자국 인용 기준선을 확인한다.

읽는 패턴(공통)

  • 각 그림은 관찰 → 해석 → 점검 순서로 읽는다.
  • 점검 단계에서는 본문 결론을 단정하지 말고, 부록의 정의·결측 조건을 함께 확인한다.

사용 팁

  • 범례 클릭: 항목 켜기·끄기
  • 마우스를 올리면: 지표 값 확인
  • 새 창: 브라우저 전체 화면으로 보기

그림 6. 출처 유형별 총 인용과 문헌당 평균 인용

무엇을 보면 좋은가

  • 관찰: 출처 유형별로 총량과 문헌당 평균의 순서 차이를 본다.
  • 해석: 인용이 많이 모이는 유형과 근거 밀도가 높은 유형은 분리해서 읽어야 한다.
  • 점검: 태그 비배타성(중복 가능)을 전제로, 유형별 패턴 차이만 우선 비교한다.

출처 유형 태그는 상호배타적 분류가 아니라 태그 기반이라, 문헌 1편이 여러 유형에 동시에 잡힐 수 있다. 따라서 아래 값은 “출처 유형 태그 단위”의 요약으로 해석한다.

그림 7. 출처 유형×도메인 구성 비중(heatmap). 주요 출처 유형과 상위 도메인

무엇을 보면 좋은가

  • 관찰: 같은 도메인의 비중이 출처 유형별로 얼마나 달라지는지 본다.
  • 해석: 구성 차이는 출처 역할·의제 차이 신호일 수 있다.
  • 점검: 미분류(unspecified) 비중이 큰 열은 세부 태깅 부족 신호로 보고 해석을 보수적으로 둔다.

값은 출처 유형 내부에서 도메인별 비중으로 정규화한 값이다. 따라서 “총량” 비교가 아니라 “구성 차이” 비교에 사용한다.

그림 9. 정책 출처 → 연구국 인용 행렬. 절대 규모와 출처 내부 비중

무엇을 보면 좋은가

  • 관찰: 왼쪽(절대 규모)과 오른쪽(출처 내부 비중)의 패턴 차이를 본다.
  • 해석: 많이 인용하는 출처와 편향된 조달선을 갖는 출처는 다를 수 있다.
  • 점검: 상위 1개국 비중과 상위 3개국 합계를 함께 보며 편중 변화를 추적한다.

왼쪽은 절대 인용 규모를 로그 스케일로 표시한다. 오른쪽은 정책 출처 내부에서의 비중을 보여준다. 정책 출처 목록에 없는 연구국은 지역 단위로 묶어 표시했다.

그림 12. 정책–연구 근거 흐름 네트워크

무엇을 보면 좋은가

  • 관찰: 상위 노드·상위 연결만 남긴 백본 경로에서 한국 연결 축이 어디로 이어지는지 본다.
  • 해석: 이 그림은 전체망이 아니라 구조 요약 지도다.
  • 점검: 거리와 위치를 정량 해석하지 말고, 연결 관계(누가 누구와 연결되는가)만 읽는다. 표시 규칙(top-3/top-5/all) 민감도는 부록 C8에서 확인한다.

레이아웃은 탐색을 돕기 위한 보조 장치다. 노드 간 거리는 절대적 지표가 아니므로, “가까움”을 정밀한 값으로 해석하지 않는다.
