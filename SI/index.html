확장 자료 안내

바로가기: 메인 보고서(PDF) · 확장 자료 안내 · 확장 본문 · 방법론·데이터 정합성 · 인터랙티브 · 부록 · 다음 질문

핵심 메시지는 먼저 메인 보고서(PDF)에서 읽고, 이 웹 페이지는 분모·정의·추가 그림이 필요할 때 들어오는 확장 자료로 쓰면 된다.

확장 자료는 메인 보고서(PDF)의 핵심 메시지를 뒷받침하는 확장 본문·방법론·인터랙티브·부록 묶음이다. 메인 보고서가 “결론 중심 요약”이라면, 확장 자료는 “근거 확인과 반복 점검을 위한 보강 층”이다.

노트

역할 분리

  • 메인 보고서(PDF): 핵심 메시지 1~2개를 빠르게 전달
  • 확장 자료(웹): 확장 서술, 지표 정의, 해석 가드레일, 추가 점검
힌트

가장 빠른 이동

  • 배경과 해석을 이어서 읽고 싶으면 확장 본문으로 간다.
  • 분모·결측·해석 경계를 먼저 확인하고 싶으면 방법론·데이터 정합성으로 간다.
  • 그림을 직접 확대해서 보고 싶으면 인터랙티브로 간다.
  • 추가 표와 정의는 부록, 다음 분기 점검 축은 다음 질문에서 확인한다.

용어·지표 요약 (30초)

이 보고서에서 자주 쓰는 용어를 “이 보고서 기준”으로만 짧게 정리했다.

용어 이 보고서에서의 의미
Overton 정책문헌의 참고문헌을 추출해 DOI 등 학술 인용과 연결한 정책문헌 인용 데이터베이스
OpenAlex 논문 메타데이터(도메인·토픽·국가·OA 등)를 제공하는 학술 데이터베이스
DOI-연결 관측 범위 Overton 정책문헌의 참고문헌 가운데 DOI가 확인되어 OpenAlex works로 연결되는 인용 범위(보고서·법령·웹 등 DOI 밖 근거는 기본 지표에 포함되지 않음)
고유 정책문헌 Overton 정책문헌을 중복 제거해 만든 “문헌 1편 단위” 분석 기준
인용 건수(citations) 정책문헌이 DOI 논문을 인용한 횟수(인용 기록 수)
고유 논문 수(works) 인용된 논문을 “서로 다른 논문” 기준으로 중복 제거한 개수
반복 인용 48.1% 인용된 고유 논문 가운데 2개 이상 서로 다른 정책문헌에서 반복 호출된 논문의 비중
최근성(recency) 2022–2024 발행 논문으로 향한 정책 인용 비중
인용 강도(intensity) 집계 단위 내 인용 건수 / 고유 논문 수(논문 1편당 평균 정책 인용수)
1저자 국가코드 연구국을 정의할 때 쓰는 기준(논문의 1저자 소속국 코드; 결측이 있어 “확인분 기준”으로 해석)
자국 인용 비중 정책 출처 국가 = 1저자 연구국인 인용의 비중(1저자 국가코드 확인분만 분모에 포함)
Field missing OpenAlex 하위 분야(field) 태깅이 비어 있는 구간(도메인 내부 구성 해석을 불안정하게 만들 수 있음)
다중라벨 논문 1편이 여러 토픽/태그에 동시에 속하는 구조(합이 100%를 넘을 수 있음)
OA(오픈액세스) 접근성의 가능한 요인으로 참고하지만, 인과로 단정하지 않음
