Extended Report — 개요

Extended Report는 메인 보고서(Data Brief)의 핵심 메시지를 뒷받침하는 확장 본문·방법론·인터랙티브·부록 묶음이다.
메인 보고서가 “결론 중심 요약”이라면, Extended Report는 “근거 확인과 반복 점검을 위한 작업 공간”이다.

Note

역할 분리

  • Data Brief (메인 PDF): 핵심 메시지 1~2개를 빠르게 전달
  • Extended Report (웹): 확장 서술, 지표 정의, 해석 가드레일, 추가 점검

구성

  1. 확장 본문: Data Brief의 배경·맥락·해석을 확장한다.
  2. 방법론·데이터 정합성: 분모/분자, 매칭·결측, 해석 가드레일을 점검한다.
  3. 인터랙티브: 주요 그림을 확대/토글/hover로 탐색한다.
  4. 부록: 커버리지·태깅, 추가 표·그림, 상세 진단을 확인한다.
  5. 다음 질문: 다음 분기 후속 분석 우선순위를 점검한다.

이 페이지에서 먼저 할 일 (2분)

  • 본문에서 막힌 지점이 있으면 먼저 Data Brief ↔︎ Extended Report 연결표를 본다.
  • 분모·결측·해석 경계가 궁금하면 방법론·데이터 정합성으로 이동한다.
  • 추가 그림·정의·후속 체크리스트가 필요하면 부록과 다음 질문으로 이동한다.

Extended Report 구조(고정)

페이지 역할 포함 범위
index.qmd 입구/내비게이션 Data Brief↔︎Extended 연결표, 빠른 찾기, 업데이트
extended_report.qmd 확장 본문 핵심 메시지의 문맥/서사/점검 프레임
methods.qmd 방법론 점검 범위/분모/결측/해석 가드레일
interactive.qmd 탐색 메인 PDF에 포함된 핵심 그림 + 확장 그림(1-12) 인터랙티브
appendix.qmd 근거/정의/추가 자료 커버리지·태깅, 상세 정의, 추가 그림
next_questions.qmd 후속 과제 확장 질문과 분석 우선순위
Note

현재 사이트 경로는 호환성을 위해 /SI/...를 유지한다.
다만 독자 표시 명칭은 모두 Extended Report로 통일한다.

Data Brief ↔︎ Extended Report 연결

아래 표에서 인터랙티브: 그림 n은 Extended Report(웹) 번호(1-12) 기준이다. 메인 PDF의 그림 번호(1-8)와 다르므로, 혼동되면 표의 링크를 기준으로 따라가면 된다.

Data Brief(메인 PDF) Extended Report에서 더 볼 것
1장 Data Insight(요약 수치/분모) 부록: 관측 범위 정의 · 부록: 반복 인용 48.1% 정의 · 방법론: 범위/분모
2장 허브(그림 1-3) 확장 본문: 2장 · 인터랙티브: 그림 5 · 인터랙티브: 그림 7 · 인터랙티브: 그림 8 · 부록: 커버리지·태깅
3장 한국(그림 4-6) 확장 본문: 3장 · 인터랙티브: 그림 11 · 인터랙티브: 그림 6 · 인터랙티브: 그림 12 · (확장: 그림 9, 그림 10)
4장 두 속도(그림 7-8) 인터랙티브: 그림 2 · 인터랙티브: 그림 4 · 부록: 최근성/인용 강도 · (확장: 그림 1, 그림 3)
5장 반복 측정/확장(점검 질문) 다음 질문 · 방법론: 업데이트 프로토콜
