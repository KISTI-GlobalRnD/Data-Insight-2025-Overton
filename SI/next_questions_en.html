This page lists three follow-up questions worth checking after reading the main report. They focus on analyses needed to validate the observed patterns or to explain “why this pattern emerges.”

Note

How this page complements the main report

  • It turns the “check questions” left in the main report into a follow-up checklist.
  • Each question is framed as a next step for validation, not as a way to lock in a conclusion.

How to use this page (1 min)

  • Read each question in the same order: observation baseline → interpretation hypothesis → checks → completion signal.
  • In this cycle, prioritize reaching a completion signal for at least one question rather than starting all three.

Prioritized follow-up questions (3)

Q1. If we include citations between policy documents, how do evidence routes change?

  • Observation baseline: The current hub reading is based on direct policy → research citation links.
  • Interpretation hypothesis: Adding a policy → policy layer may change hub definitions and top-channel ordering.
  • Checks: Identify hubs in the policy-to-policy network, identify evidence-synthesizer documents, and compare direct routes with mediated routes during crisis periods.
  • Completion signal: Hub reordering is quantitatively confirmed against the direct-only network, with changes tied to specific periods/source types.

Q2. If we read citation context, can the same citation mean different things?

  • Observation baseline: The same DOI citation count can still reflect different functions (evidence/background/critique).
  • Interpretation hypothesis: Separating citation functions may change hub strength and topic-maturity interpretation.
  • Checks: Classify citation functions using sentence/paragraph embeddings, split evidence-use citations from mention-only citations, and track topic-level context-shift patterns.
  • Completion signal: At least two topics show “similar citation counts but different function mix,” with an explicit change in hub interpretation.

Q3. From a network perspective, what diffusion patterns does evidence follow?

  • Observation baseline: The report shows major routes, but diffusion dynamics (speed/threshold/resilience) need separate testing.
  • Interpretation hypothesis: In crisis periods, hub dependence and diffusion speed rise together, increasing fragility to hub disruption.
  • Checks: Estimate diffusion-speed indicators, detect threshold-like surge windows, run hub-removal fragility/resilience scenarios.
  • Completion signal: Crisis and non-crisis diffusion parameters diverge, and vulnerable hub candidates are prioritized for monitoring.

Additional extension ideas (optional)

The following tracks can run in parallel as update/extension options.

  • Recompute after NKIS linkage: Link domestic policy documents (NKIS) and global policy documents (Overton) via identifiers, then recompute Korea metrics in the same frame.
  • Break down by SDGs/agendas: Read policy agenda tags together with OpenAlex topics to compare repeated evidence calls by agenda.
  • Include evidence beyond DOIs: Quantify non-DOI evidence (reports, legislation, web) and integrate with DOI-based links.
