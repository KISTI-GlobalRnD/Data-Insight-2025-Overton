Extended Report — Overview

Korean page

The Extended Report is the companion layer to the main report (PDF). While the PDF keeps headline messages short, this web layer keeps the extended narrative, method checks, diagnostics, and interactive exploration in one place.

Note

Role split

  • Main report (PDF): concise headline messages
  • Extended Report (web): extended text, method checks, interpretation guardrails, and follow-up diagnostics

Structure

  1. Extended report: narrative expansion of the main report
  2. Methods & data validity: scope, denominators, matching/missingness, guardrails
  3. Interactive: zoom/toggle/inspect key figures
  4. Appendix: coverage/tagging notes and extra figures
  5. Next questions: next-cycle follow-up checklist

Start here (2 min)

  • If you are blocked in the main report, check the Main report ↔︎ Extended Report map first.
  • If denominator/missingness interpretation is unclear, move to Methods.
  • If you need extra figures/definitions/checklists, move to Appendix and Next questions.
