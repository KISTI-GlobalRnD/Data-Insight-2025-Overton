공개 재현성

Overton × OpenAlex 보고서의 공개 코드·집계표·실행환경·검증 절차를 제공한다.

바로가기: 보고서 원고(PDF) · 확장 자료 · 방법론·데이터 정합성 · 인터랙티브 · 부록 · 공개 재현성 · 다음 질문

이 페이지는 보고서의 공개 가능한 재현 범위를 정확히 구분한다. Overton 원자료와 원자료에서 파생된 개별 기록은 이용 조건에 따라 배포하지 않는다. 공개 자료만으로는 핵심 수치와 보조 비교값을 다시 계산하고, 사용된 코드·집계표·환경을 확인할 수 있다.

공개 웹 산출물은 GitHub 저장소에서 확인할 수 있다. 저장소 커밋과 별개로 각 배포 묶음의 정확한 버전은 SHA256SUMS.txt의 체크섬으로 식별한다.

원자료 없이 다시 확인할 수 있는 값

공개 검증 스크립트는 다음 값을 집계표에서 다시 계산한다.

  • 한국 연구를 인용한 미국·국제기구·영국 정책 출처의 합계 비중
  • 한국 정책문헌이 인용한 미국 연구 비중
  • 한국의 두 인용 방향에서 사회과학·보건과학이 차지하는 비중
  • 한국 정책문헌 도메인 구성과 도메인별 미국 논문 구성비를 결합한 36.1% 보조 비교값
  • 연구국 순차 부여와 민감도 분석의 기준 인용 수
  • 국가별 도메인 구성비 캐시가 연구국 순차 부여 규칙과 원천 parquet의 크기·수정시각에 일치하는지

코드 묶음과 집계표 묶음을 같은 디렉터리에 풀고 다음 명령을 실행한다.

python scripts/verify_public_report_aggregates.py --root . --run-tag 20251026

모든 검사가 통과하면 마지막 줄에 PUBLIC_AGGREGATE_VERIFICATION=PASS가 출력된다. 이 검증은 보고서의 핵심 관측값을 확인하는 절차이며 Overton 원자료의 완전한 재수집을 뜻하지 않는다.

전체 재생성에 필요한 추가 입력

원자료에서 중복 제거 집계와 전체 그림을 다시 생성하려면 다음 입력이 필요하다.

  • Overton 정책문헌과 DOI 인용 원자료
  • 정책 출처 국가·유형 메타데이터
  • 보고서 스냅샷에 맞춘 OpenAlex 논문·저자·토픽 정보

입력 경로와 실행 순서는 코드 묶음의 Data_Insight/Report/Report_Runbook.md에 정리되어 있다. 공개 코드에는 자격증명이나 로컬 전용 노트북을 포함하지 않는다.

실행환경과 버전 식별

기준 환경은 Python 3.12, Quarto 1.4.550, Pandoc 3.1.3, Google Chrome 150이며 주요 Python 패키지의 정확한 버전은 환경 목록과 매니페스트에 기록했다. 원고 발행일은 2025-12-31, 집계 실행 태그는 20251026, 데이터 스냅샷은 Overton 2025.02와 OpenAlex 2025.06이다.
