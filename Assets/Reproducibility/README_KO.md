# Overton × OpenAlex 보고서 공개 재현성 자료

## 공개 범위

이 자료는 원고 발행일 2025-12-31과 실행 태그 20251026을 기준으로 한다. 공개 집계표, 핵심 수치 검증 스크립트, 보고서·그림 생성 코드, 실행환경 목록을 제공한다.

Overton 원자료와 원자료에서 파생된 개별 정책문헌·논문 수준 기록은 이용 조건에 따라 포함하지 않는다. 따라서 공개 자료만으로 가능한 범위는 다음과 같다.

- 보고서의 핵심 관측값과 분야별 국가 연구 규모를 반영한 기대 비중 재계산
- 공개 집계표와 보고서 생성 코드의 확인
- 동일한 공개 집계표를 이용한 표·그림의 감사

원자료부터 모든 집계표를 다시 생성하려면 별도의 Overton 이용 권한과 보고서 실행 안내에 명시된 로컬 입력 파일이 필요하다.

## 빠른 검증

코드 묶음과 집계표 묶음을 같은 디렉터리에 풀고 다음 명령을 실행한다.

```bash
python scripts/verify_public_report_aggregates.py --root . --run-tag 20251026
```

검증 스크립트는 한국의 두 가지 인용 방향, 사회·보건과학 구성비, 사회과학 비중 차이의 출처 유형 구성·동일 유형 내부 구성 요소, KDI·KIEP 합계 비중, 두 가지 방향의 싱크탱크 비중, 11개국 분야 차이 비교에서 한국의 순위, 11개국 싱크탱크 인용 비중과 유형 내부 기관 집중도, KDI·KIEP 인용 토픽 유사 해외 싱크탱크 25곳의 국가 수·사회과학 비중 범위, 미국 연구의 36.1% 결합 표본 구성 기반 기대 비중을 다시 계산한다. 또한 연구 국가 결측의 층화값과 기계적 경계, 분야 차이 가중 민감도, 기관 문헌·인용 밀도, 저자 국가 민감도 기준 수치, 캐시 출처 정보를 확인한다. `PUBLIC_AGGREGATE_VERIFICATION=PASS`는 공개 집계값과 계산 관계가 통과했다는 뜻이며, 라이선스 원자료나 Overton 상류 추출 모집단을 재생성했다는 뜻은 아니다.

## 파일 버전

`REPRODUCIBILITY_MANIFEST.json`은 공개 파일의 경로·크기·SHA-256, 실행환경, 연구 국가 부여 규칙과 국가별 도메인 구성비 캐시의 원천 정보를 기록한다. 배포 묶음 자체의 SHA-256은 `SHA256SUMS.txt`에서 확인한다. Git 커밋과 별개로 이 체크섬이 정확한 배포 파일 버전을 식별한다.
